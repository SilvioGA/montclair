# CATA

Tienda de decants y combos. Astro + Tailwind.

## Arrancar

```bash
cd Desktop/cata
npm install
npm run dev
```

Abre `http://localhost:4321`.

## Pedidos

Los pedidos salen por WhatsApp. Cambia el número en `src/data/config.ts`.

El vendedor prende o apaga un perfume con `available` en `src/data/catalog.ts`.
